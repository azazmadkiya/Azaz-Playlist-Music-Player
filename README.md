# Azaz Playlist Music Player 🎵

A clean, modern, and feature-rich music streaming web application powered by YouTube playlist links, curated audio tracks, and background playback support. Built with React, Vite, Tailwind CSS, and TypeScript.

---

## ✨ Key Features

- **Custom YouTube Playlist & Video Links**: Instantly paste any YouTube playlist link or video URL in the front-and-center input bar to stream your favorite music.
- **Background & Minimized Playback**: Powered by the **Media Session API**, your music continues playing seamlessly even when you minimize Chrome, switch apps, or lock your device. Supports lock screen and keyboard media controls (Play, Pause, Previous, Next).
- **Featured Playlists & Curated Tracks**: Switch effortlessly between curated audio tracks and popular preset playlists.
- **Blogger Ready**: Includes a fully responsive XML Blogger theme template (`/public/blogger-theme.xml`) ready for publishing on Google Blogger.
- **Modern Responsive UI**: Built with Tailwind CSS, lucide-react icons, and smooth animations.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/azazmadkiya/azaz-playlist-music-player.git
   cd azaz-playlist-music-player
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
